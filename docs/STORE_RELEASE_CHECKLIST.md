# Store Release Checklist

## Android Checklist
- [ ] Package ID configured correctly
- [ ] App signing key configured
- [ ] Adaptive icon & notification icon assets present
- [ ] Splash screen configured
- [ ] Version code & name updated
- [ ] Permissions (Location, Notification) reviewed
- [ ] Foreground service declarations (Location/Nav) present
- [ ] Play Store screenshots updated
- [ ] Privacy & Data Safety form updated
- [ ] Release AAB generated
- [ ] ProGuard/R8 mapping files saved

## iOS Checklist
- [ ] Bundle ID configured correctly
- [ ] App icons assets updated
- [ ] Info.plist permissions (Location Always, Location When In Use) reviewed
- [ ] Privacy manifests generated
- [ ] Signing & provisioning profiles valid
- [ ] CarPlay entitlement reviewed (BLOCKED_EXTERNAL)
- [ ] App Store privacy declarations updated
