## Decision Criteria

4. SDK capability (Flutter integration)

6. Two-wheeler specific routing
7. Turn-by-turn instruction quality
8. Offline capabilities
9. Speed limit data accuracy
10. Incident reporting APIs
11. Geocoding accuracy for Indian addresses
12. Support SLAs
13. API rate limits
14. Data privacy requirements
15. Battery consumption of SDK
16. Customization of map styles
17. Compliance with Indian geospatial regulations
